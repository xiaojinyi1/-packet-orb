## 1. 一句话产品

**把你的网络路径变成一座可以滚过去的夜光低多边形迷宫。** 粘贴一段 traceroute，浏览器生成一座小镇：每一跳是一栋路由器建筑，路段长度由延迟决定，丢包是塌方的桥，匿名跳是迷雾隧道，ASN 变更是过境的关卡。你操控一颗发光的数据包球滚完全程，到站即结算。

## 2. 体验剧本

1. **开场（0–8s）**：加载即演出。黑屏 → 一颗数据包球从屏幕上方掉下，砸在地面弹两下（物理演出），镜头拉起，露出整座迷宫小镇。地面大字：`DRAG TO AIM · SPACE TO LAUNCH`（桌面）/ 单指拖拽（移动端）。
2. **输入（第一次交互）**：右下终端面板。默认已加载样本 `Wuhan → Cloudflare`，玩家可以直接滚；也可以粘贴自己的 trace，回车 → 世界在 1.2s 内重建（地形形变动画，不是刷新页面）。
3. **探索**：沿路网滚动，逐跳经过时建筑顶灯亮起，地面涂装浮出 IP / 主机名 / 该跳 RTT。路段有坡、有坑、有蹦床、有迷雾隧道。
4. **高潮**：跨洋段做成"海底隧道"（暗蓝、水波 shader、球体减速），出隧道瞬间视野豁然开朗，境外骨干区色板切换。
5. **到站**：终点机房发光门。触发结算：逐跳延迟瀑布、最毒一跳高亮、丢包路段回放（镜头重走一遍）。
6. **分享**：生成一条把整份 trace 编码进去的 URL（世界可复现），或录制前 8 秒的 GIF/WebM 短片。

## 3. 视觉语言（Bruno Simon 风格的落地规格）

Bruno 作品的可复制要素与本项目的执行方式：

| 手法 | 执行规格 |
|---|---|
| Low-poly + 明亮撞色 | 平面着色（flatShading），几何不做圆滑；建筑用盒体+屋顶切角，不做细节雕刻 |
| "没有灯"的材质技巧 | 全场 **matcap** 材质为主，不用实时 PBR 光照；仅数据包球与终点门用 emissive。省下的开销全部投给物理与粒子 |
| 真实刚体世界 | 世界元素几乎都是 kinematic/static body，可撞物是 dynamic body；球体与路障碰撞有明确反馈（弹飞 + 烟尘粒子 + 音效） |
| 分区地图 | 5 个区：起点家园区 → 城域骨干区 → 省级枢纽区 → 跨洋隧道 → 目标机房区（分区来自 ASN/geo，缺失时按 TTL 均分） |
| 文字写在地面/路牌 | 关键数值（ttl、rtt、loss）刷成地面涂装与路牌，**不做 UI 弹窗堆叠**；HUD 只在右下角留最小信息 |
| 彩蛋 + 成就系统 | 见第 8 节 |
| 全输入支持 | 键盘 / 触屏摇杆 / 手柄（Gamepad API），切换输入源时提示文案自动更换 |
| 包体纪律 | 参考 Bruno 约 2MB 量级的自律：Draco 压缩 glTF、KTX2/Basis 纹理、按需加载、InstancedMesh 铺建筑 |

**色板（双主题，默认 Night）**

- Night（主打，发光球体更有戏）：夜空 `#161233` → `#2E1F5B` 渐变；地面奶油灰 `#D9D2C5`；骨干区高饱和青 `#2ED3C6`；城域区橘 `#FF7A45`；丢包危险物 品红 `#FF2E88`；终点门 柠檬黄 `#FFE447`
- Day：沙橙地 + 薄荷建筑 + 暮紫阴影（更接近 Bruno 原味沙漠调）
- 规则：**每种 ASN 绑定一个主题色**，玩家凭颜色就能认出"现在走到谁家网络里了"

**几何与性能预算**（硬约束）

- 静态场景 ≤ 120k 三角面；建筑用 InstancedMesh，单材质组 ≤ 18 个；draw call ≤ 120
- 阴影只开一张 directional shadow map（2048），远景改烘焙 AO 贴图
- 首屏资源 ≤ 4MB（gzip 后），可交互时间目标 < 3.5s（4G）

**字体**：数字用等宽（JetBrains Mono 风格），标题用超粗无衬线。地面文字一律**预烘焙进纹理图集**，不用运行时 SDF 字体库，省包体也省性能。

## 4. Packet Orb 手感设计

这是整个项目"炫不炫"的分水岭，优先级最高。

- **球体**：icosphere detail=2（低模感），半径 0.45 世界单位，外壳半透明 matcap + 内核点阵自转 + 12 顶点脉冲。
- **物理参数**：mass 1.2，linearDamping 0.28，angularDamping 0.32，restitution 0.52（普通路面）/ 0.88（丢包蹦床）/ 0.2（隧道泥地），滚动摩擦 0.02。
- **操控采用混合驱动**：纯力矩（torque）最真实但手感发飘、原地打转难；纯直接力又会滑步不像球。折中：**70% 力矩 + 30% 直接力**（drive assist，随速度升高自动降低 assist 比例）。这一条必须做成可调参数，调试面板留滑杆。
- **两种模式（关键决策）**：
  - `自由驾驶`：WASD / 摇杆，物理全开，可飞出地图、可撞墙、可作弊抄近路（抄近路会触发"重路由"惩罚动画）。
  - `轨道投递`（默认给观赏者）：拖拽蓄力 → 松手沿主路径弹射，镜头跟随，纯享受画面。这条模式保证"不会玩的人 3 秒内也觉得爽"，是作品集传播的关键。
- **镜头**：camera-controls 阻尼跟随，位置滞后 0.18s，看向球体前方 4 单位；速度越高 FOV 越大（65 → 78），落地瞬间压回，制造冲击。
- **反馈层**：拖尾（渐变 additive ribbon，长度随速度）、碰撞烟尘粒子、每跳触发的"叮"音（Howler）、速度表用球体发光强度表达而非仪表。
- **降级**：低端机关掉拖尾与粒子，只保留球体发光。

## 5. 数据 → 迷宫：生成规则（核心）

| 数据字段 | 空间表达 | 备注 |
|---|---|---|
| `ttl` | 关卡编号，路牌 + 地面大字 | 每 5 跳一个里程碑拱门 |
| `rtt_avg` | 路段长度 = `12 + 8·sqrt(rtt)` 米 | **用 sqrt 压缩**，否则跨洋 300ms 会拉出 2km 直路；HUD 保留精确数值兜底 |
| 相邻跳 `Δrtt` | 坡度：Δ>15ms 上坡（+6°~+12°）、Δ<-10ms 下坡；Δ>60ms 发卡弯 | 视觉化"延迟突然出现在这一跳" |
| `loss%` | 0 平滑路；<10% 减速带；10–30% 坑洞（球体会颠）；>30% 断裂跳台（大弹跳 + 慢镜） | 丢包越高越好玩，这是"数据准确性次之"的正向收益 |
| `rtt` 标准差（jitter） | 弹性系数 → 弹簧桥/蹦床区 | 高抖动段直接做成蹦床 |
| 全 `*` 匿名跳 | **迷雾隧道**：雾墙、可视 6m、内置微弱霓虹引导线，穿出后给视觉奖励 | 现实里中段大量匿名，隧道化正好让缺失也好看 |
| 同跳多地址 / ECMP | **分岔口**，两条可选路线（不同延迟表现） | 提供重玩性 |
| ASN 变更 | 国境关卡：发光拱门 + 地面色板与建筑风格整体切换 | 记忆点最强的一处设计 |
| `geo` | 城市名刷成地面涂装 + 地标剪影（东方明珠/金门等低模剪影） | **仅做主题标签，不做真实经纬度投影**（IP 定位误差太大） |
| 私有地址（10./192.168.） | 固定"家园区"：小房子 + 光猫造型塔 = 出发台 | 保证起点永远有归属感 |
| 重复出现的 IP | **路由环路 → 无限回廊彩蛋关卡** | 撞进去触发成就 |
| 末跳 vs 倒数二跳延迟回落 | 判定"到达目的地"，终点机房发光门 | |
| MTU / 分片线索 | 限宽门（球体需要减压才能过） | 可选彩蛋 |

布局算法顺序：先按 TTL 链生成主干折线（带坡度）→ 插入分岔（ECMP）→ 按 ASN 切段并做区域形变（抬高/下沉形成天然分区边界）→ 沿段布建筑与路障（InstancedMesh + 泊松盘采样避免重叠）→ 叠加语义装饰（坑、蹦床、隧道、门）→ 烘焙静态碰撞体网格。

## 6. 解析器规格（A+B 路线的成败点）

必须一次吃掉三种格式，且**容错优先于严格**：

1. **Unix/BSD `traceroute`**：` 1  gw (192.168.1.1)  1.234 ms  1.100 ms  1.400 ms`，也支持 `traceroute -A`（带 AS 后缀）、IPv6、`* * *` 行。
2. **Windows `tracert`**：`  1     2ms     1ms     2ms  192.168.1.1`，含中文提示行 `通过最多 30 个跃点跟踪...` 需跳过。
3. **`mtr`**：优先 `--json`，其次 `--report`/`-r` 宽表（` 1:  [192.168.1.1]  0.0%  3  1.2  1.1  1.4 ...`）。
4. 兜底：逐行正则 + 置信度打分，识别失败时给"请贴 mtr -r 或 traceroute 原始输出"的示例提示，并允许用户点"按最长匹配强行解析"。

归一化 schema（渲染层只认它，未来接后端探针只换 Source）：

```jsonc
{
  "schema": "packet-orb/1",
  "source": "paste | builtin | probe",
  "capturedAt": "2026-11-04T09:28:00+08:00",
  "target": { "host": "www.example.com", "ip": "104.16.0.0" },
  "hops": [
    { "ttl": 1, "addresses": ["192.168.1.1"], "ptr": "router", "private": true,
      "samplesMs": [1.2, 1.1, 1.4], "avgMs": 1.23, "bestMs": 1.1, "worstMs": 1.4,
      "stddevMs": 0.13, "lossPct": 0, "as": null, "geo": null, "anonymous": false },
    { "ttl": 6, "addresses": ["202.97.60.1"], "ptr": "chinanet-bb",
      "samplesMs": [38, 39, 41], "avgMs": 39.3, "lossPct": 33,
      "as": "AS4134", "geo": "CN/SH", "anonymous": false }
  ],
  "quality": { "parsed": 12, "anonymous": 4, "confidence": 0.83 }
}
```

校验与降级规则：样本数 n≥3 视为可信，n<3 标灰；全 `*` 且连续 ≥4 跳 → 合并成一条"长迷雾隧道"（避免迷宫被 20 段重复雾墙毁掉节奏）；跳数 > 30 截断并提示。

**内置样本库（首发 5 条，覆盖不同视觉戏型）**：家→局域网内超时（全雾型）、武汉电信→国内云（骨干高延迟突增型）、→Cloudflare 美西（跨洋隧道 + ASN 关卡多）、→日本（短路径 + 高抖动蹦床多）、一条坏样本（中段全丢包，展示跳台玩法）。

## 7. 技术栈与模块结构

- **构建**：Vite + TypeScript，**vanilla，不引入 React/Vue**（贴近 Bruno 的工程形态，渲染循环与状态更好控，包体更小）。
- **渲染**：Three.js r18x，WebGL2 为主路径，WebGPU 留 feature flag（不阻塞交付）。
- **物理**：`@dimforge/rapier3d-compat`（WASM，放 Web Worker，固定步长 1/60，插值渲染）；轻量场景可切 `camera-cannon-es` 作为退路。
- **动画/镜头**：`camera-controls` + `gsap`；音效 `howler`；调试面板 `tweakpane`（按 `/` 呼出，逐层开关 terrain/buildings/fx/physics，这是 Bruno 工作流里的生产力核心，务必做）。
- **资源**：Blender 出 low-poly 资产 → glTF + Draco；纹理 KTX2/Basis；单张 matcap 图集复用。

## 8. 彩蛋与成就（12 条，作品集的自来水来源）

1. 把球滚出地图边界（"你是从哪里来的？"）→ 掉进星空 void，慢慢飘回起点
2. 撞塌全部减速带 → 路政车出场（纯演出，无逻辑）
3. 进入路由环路无限回廊
4. 在迷雾隧道里关掉雾（连续按三下 `F`）看到"其实没有路"
5. 用 `轨道投递` 一次不停直达终点 → "零丢包送达"
6. 抄近路越界 → 触发"重路由"惩罚：地面塌一块，出现新的绕行山
7. 撞终点门 3 次不开 → 门自己裂开（Bruno 式"墙坏了也能过"）
8. 粘贴一段全是 `*` 的 trace → 世界生成纯白迷雾，弹出"你的运营商把一切都藏起来了"
9. 半夜 0–5 点访问 → 场景切换为萤火虫版夜网
10. 长按 `R` 3 秒 → 反向播放：球从终点退回你家
11. 手柄输入 → 隐藏标题界面
12. 分享 URL 带 `?e=1` → 全部彩蛋解锁（给同行演示用）

## 9. "数据准确性次之"具体让在哪（诚实清单）

写进 README，避免被同行误读为监控工具：

- 路段距离按 `sqrt(rtt)` 压缩，**不是线性比例**；精确数值只在 HUD 与结算面板出现。
- 允许无数据支撑的装饰地形（远山、树、路灯），只为构图与节奏。
- 匿名跳合并成隧道，会抹掉真实跳数粒度。
- 结算只给"哪一段最差"的相对结论，不做 SLA/绝对质量判断。
- 不做真实经纬度地图投影（IP 定位误差可达数十至上百 km，投影反而误导）。

## 10. 性能、无障碍与降级

- **画质三档**（自动探测 GPU tier + 手动切换）：High（bloom+DOF+粒子+阴影）/ Medium（bloom+阴影，去 DOF）/ Low（仅 matcap+基础阴影）。目标：桌面 60fps、中端安卓 30fps。
- **2D 降级方案**：WebGL 不可用或用户主动选择时，渲染同一份 layout 结果的 SVG 俯视迷宫（不做第二套数据逻辑），保证 100% 可访问。
- `prefers-reduced-motion`：关闭镜头震动、慢镜与自动旋转。
- 移动端：左摇杆 + 右视口拖拽；`轨道投递` 模式设为默认（手机驾驶体验天然差）。
- 加载策略：骨架场景（球 + 主干路 + 起终点）先出，装饰资产分帧流式加载；首帧可交互 < 3.5s。

## 12. 风险与对策

1. **迷宫+3D 易眩晕/迷路** → 主干路永远有霓虹引导线；小地图用一条竖直的"跳数进度条"而非俯视雷达；`轨道投递` 兜底。
2. **真实数据太脏（中段全 `*`）导致世界难看** → 已在生成规则里把"缺失"转成迷雾隧道这一视觉资产；内置样本库负责"第一眼一定好看"。
3. **物理引擎在 WASM+Worker 下调试成本高** → M0 阶段先跑通 worker 通信，别等到最后；预留 cannon-es 退路。
4. **项目膨胀失控**（3D 网站通病）→ 每周一次包体审计，超预算就砍装饰资产，不砍玩法。
5. **风格侵权风险** → 只借语言（low-poly/matcap/物理/彩蛋），模型与贴图全部自制，不提取 Bruno 的 folio 资产。
6. **浏览器无法自行 traceroute 的误解**（用户可能问"为什么不直接测我的网"）→ 首页一句话说明：浏览器拿不到原始网络报文，所以给你三种数据入口。
